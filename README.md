## ✨ المميزات

### 🧠 Tri-Lobe Architecture
بنية ثلاثية الفصوص مستوحاة من الدماغ البشري

### 🇸🇦 دعم عربي أصلي
- فهم اللهجات السعودية والخليجية
- معالجة النصوص من اليمين لليسار (RTL)
- واجهة عربية كاملة

### 🔒 خصوصية مطلقة
- لا سيرفرات خارجية
- لا تتبع
- بياناتك تبقى عندك

### ⚡ أداء خارق
- يعمل في المتصفح مباشرة
- لا يحتاج تثبيت
- سريع وخفيف

## 🚀 البداية السريعة

```bash
# 1. حمّل المشروع
git clone https://github.com/gratechx/cometx.git

# 2. ادخل المجلد
cd cometx

# 3. شغّل
npm install && npm start
```
